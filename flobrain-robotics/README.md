# CAIPO Robotics

Robotics-focused runtime built on top of CAIPO Core.
Controls locomotion, perception modules, and drives servos/motors.

## Purpose
- Robot behaviors
- Motor control
- Sensor integration for embodied devices

## Status
Planned. Previous firmware archived in `legacy/`.

See [`docs/ROBOTICS_ASSESSMENT.md`](../docs/ROBOTICS_ASSESSMENT.md) for the full
technical assessment (implementation status, hardware/BOM review, gaps, and a
5-milestone roadmap).
