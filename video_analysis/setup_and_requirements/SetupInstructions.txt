Setup Instructions

1. Clone the repository

git clone https://github.com/FlomadLabsRD/Caipo-flomad-labs-updated.git
cd Caipo-flomad-labs-updated
git checkout myVideoAnalysis

2. Install dependencies
pip install -r requirements.txt

Callers must export HF_HUB_TOKEN (or run huggingface-cli login) to pull BLIP/LLaVA models, or else stub captions will be used.

3. Environment Setup
export PYTHONPATH=. (or pip install -e .)

4. Hugging Face Authentification
The BLIP and LLaVA models require Hugging Face credentials.
Export token before running:
export HF_HUB_TOKEN="your_hf_token_here"
or login with CLI:
huggingface-cli login

If no token is provided, the system will fallback to stub captions, which are fast and require no downloads.

5. How to Run 
Place your video file in the root folder and update the path in the script:
VIDEO_PATH = "test_clip.mp4"

Run the script: 
# Run with stub model (CI-safe)
python mergeModels.py --video test_clip.mp4 --model stub --fps 8.0

# Run with real models (requires HF token & GPU)
python mergeModels.py --video test_clip.mp4 --model blip --fps 0.1
python mergeModels.py --video test_clip.mp4 --model llava --fps 0.1

6. Model Info
Captioning model: BLIP (Salesforce) (visual_caption.py)
Used to generate scene-level descriptions from video frames.
Captioning Model: LLaVA-1.5-7B (Hugging Face) (llavamodelcaptions.py)
Multimodal large language model for vision + language tasks, used here for detailed frame-level descriptions.
Embedding model: all-MiniLM-L6-v2
Converts captions into dense vector embeddings for semantic understanding.

Indexing & Search
FAISS (Facebook AI Similarity Search):
Efficient library for indexing and performing similarity search on the embeddings.

7. Data Flow Overview
video.mp4
   ↓
frames/ [frame_0000.jpg, ...]
   ↓
captions.json (blip | llava | stub)
   ↓
sentence-transformers → embeddings
   ↓
FAISS index
   ↓
ask.py  ← user question → Answer
